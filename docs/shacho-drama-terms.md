## A. 送付用ご案内文面（LINE / DMにそのまま貼れます）

このたびは社長ショートドラマ企画にご参加いただきありがとうございます。
本格制作に入る前に、進め方と条件をまとめましたのでご確認ください。
気持ちよく、いいものを一緒に作るための取り決めです。

### ■ 無料でお作りするもの

- 縦型ショートドラマ 全4話（Instagram / TikTok / YouTube Shorts 対応）
- 総集編 1本
- 企画・構成・脚本・映像制作・編集・テロップまで一式

※通常価格 25万円相当の内容を、今回は特別に無料でご提供しています。

### ■ ご参加の条件（無料制作の前提となります）

無料でお受けする代わりに、以下4点をお願いしています。

1. **本人アカウントでの投稿（共同投稿）**
   納品後7日以内に、ご本人のアカウントで投稿してください。
   その際、Instagramの「共同投稿者」機能で弊社アカウントを共同投稿者に設定してください。
   投稿は6ヶ月間、削除せずに残していただきます。

2. **制作クレジット＋タグ付け**
   キャプションに制作元として弊社名を記載し、弊社公式アカウントをタグ付け・メンションしてください。

3. **ストーリーでのご紹介**
   第1話公開時と総集編公開時の計2回、ストーリーズで弊社アカウントをメンションしてご紹介ください。

4. **弊社での二次利用のご許可**
   完成した動画を、弊社の実績紹介・公式アカウントでの再投稿・営業資料・広告素材として使用させていただきます。

### ■ 進め方と確認のお願い

1. ヒアリング（エピソードのお伺い）
2. 構成案のご確認
3. 脚本のご確認 ← **ここが内容を決める最終地点です**
4. 映像制作
5. 完成尺の納品

**脚本のご確認が、内容を大きく変えられる最後のタイミングです。**
映像化に入ってからの構成変更は作り直しになるため、脚本段階でご遠慮なくお申し付けください。

お願い：
- 確認のご依頼から **3営業日以内にお返事がない場合は、ご承認いただいたもの** として次の工程に進みます。
- 写真・ロゴなどの素材は、ご依頼から**7日以内**にご提出をお願いします。
- **2週間ご連絡が取れない場合は、いったん制作終了**とさせていただきます（再開は別途お見積り）。
- ご連絡はLINE（またはDM）1本に統一させてください。複数窓口だと行き違いが起きるためです。

### ■ 修正について

完成尺の納品後、**1回・軽微修正のみ**を無料で承ります。
ご依頼は納品後3日以内に、1通にまとめてお送りください。

**無料修正に含まれるもの（軽微修正）**
- テロップの誤字・表記ゆれの修正
- 事実誤認（社名・年号・数字・固有名詞など）の訂正
- BGM・効果音の音量調整
- 尺の微調整（±3秒程度）
- ご提供済み素材（写真・ロゴ）の差し替え

**無料修正に含まれないもの（別途お見積り）**
- 構成・脚本の変更、セリフやナレーションの書き直し
- シーン・カットの作り直し、再生成
- 登場人物のビジュアル変更
- 演出方向・トーンの変更
- 全体の作り直し

## B. 社内運用メモ（相手には渡さない）

### 各条項の狙い

| 条項 | 狙い |
|---|---|
| 共同投稿を必須 | 4話＋総集編を無料で出す唯一の対価。相手のフォロワーが弊社の資産になる。ここが飲めない相手は無料対象から外す |
| 脚本確認を「内容を決める最終地点」と明言 | 映像後の構成変更を断る根拠。ここを先に握れば「言った/言わない」が消える |
| 3営業日で承認みなし | 放置されて工程が止まるのを防ぐ。後出し修正の予防線 |
| 2週間で自動終了 | フェードアウト案件の在庫化を防ぐ |
| 修正は1回・軽微のみ・3日以内・1通にまとめて | 「小分けで何度も送る」を封じるのが本質。回数より"まとめて1通"が効く |
| 料金表を明示 | 断るのではなく選ばせる形にする。細かい注文＝売上に変換される |
| 連絡窓口の一本化 | 複数チャネルで別々に依頼が来る消耗を防ぐ |

### 想定される揉め方と返し方

**「ここ、もうちょっとこうできない？」が映像納品後に来たとき**
> 「ご要望ありがとうございます。こちらは演出変更にあたるため、追加◯円でお受けできます。無料枠の軽微修正でしたら△△の部分が対象になりますが、いかがいたしましょう？」

判断を相手に返す。断らない、値引きしない、その場で決めない。

**「無料って言ったよね？」と言われたとき**
> 「はい、4話＋総集編の制作は無料でご提供しています。そのうえで、作り直しにあたる部分は別途とさせていただいております（規定◯項）」

規定を根拠にする。感情で返さない。事前提示しているので通る。

**投稿してくれない／共同投稿を渋られたとき**
これは料金ではなく前提条件の不履行。制作前に確定させる。渋る時点で、その相手は無料対象にしない。
拡散が期待できないなら、無料でやる理由が消える。

### 運用ルール

- **相手によって条件を変えない。** 畠くんのようにスムーズな人が損をする運用にすると、紹介が止まる。基準は人ではなくルールに置く。
- **規定の同意は制作着手前に必ず取る。** 「規定確認しました」の返信をスクショで保管。着手後の提示は効力が落ちる。
- **腹が立つ相手ほど、規定が仕事をする。** 感情でやりとりせず、条項番号で返す。
