# 社長ショートドラマ LINE送信用 案内文

最終更新：2026-08-23

送信前に置換してください：
- `〇〇さん` → 相手のお名前
- `【会社名】` → 弊社名
- `【@アカウント名】` → 弊社公式アカウントID

## パターンA：分割送信版（推奨・全5通）

LINEは1通が長いと読み飛ばされるので、5通に分けて連続送信します。
相手が途中で返信してきたら、そこで一度受け止めてから続きを送ってOK。

### 【1通目】前置き

```
〇〇さん

お世話になっております。
社長ショートドラマの件、本格的な制作に入る前に、進め方と条件をまとめてお送りします。

気持ちよく、いいものを一緒に作るための取り決めなので、お目通しいただけると嬉しいです。
少し長くなるので、何通かに分けてお送りしますね🙇‍♀️
```

### 【2通目】制作内容とお願いしたいこと

```

・縦型ショートドラマ 全4話
　（Instagram / TikTok / YouTube Shorts対応）

通常25万円相当の内容を、今回は特別に無料でご提供しています。

■ お願いしたい4つのこと

無料でお受けする代わりに、以下をお願いしております。

①ご本人アカウントでの投稿（共同投稿）
納品後7日以内にご投稿ください。その際、Instagramの「共同投稿者」機能で弊社アカウントを共同投稿者に設定をお願いします。投稿は6ヶ月間は残していただけると助かります。

②制作クレジット＋タグ付け
キャプションに制作元として【会社名】を記載いただき、【@アカウント名】をタグ付け・メンションしてください。

③ストーリーでのご紹介
第1話の公開時と総集編の公開時、計2回ストーリーズで【@アカウント名】をメンションしてご紹介ください。

④弊社での二次利用のご許可
完成した動画を、弊社の実績紹介・公式アカウントでの再投稿・営業資料として使わせていただきます。
```

## 送信時の注意（社内用）

- **必ず制作着手「前」に送る。** 着手後だと条件が後付けに見えて効力が落ちる。
- **「規定確認しました」の返信は必ずスクショで保管。** これが後で揉めたときの唯一の根拠になる。
- **相手によって条件を変えない。** スムーズな人が損をする運用にすると紹介が止まる。
- **①の共同投稿を渋られたら、その時点で無料対象から外す。** 拡散リターンが消えるなら無料でやる理由がない。金額を提示して有料案件に切り替える。
- 返信がなかなか来ない相手には、2〜3日後に「先日お送りした内容、ご確認いただけましたでしょうか？ご不明点あればお気軽に🙇‍♀️」と軽く一度だけリマインド。
