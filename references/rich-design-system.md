# リッチデザインシステム参照ガイド

## 基本哲学

プレミアムデザインは装飾の量ではなく、以下で作る：

- **階層（Hierarchy）**：何が最も重要かを一目で伝える
- **奥行き（Depth）**：レイヤー・影・グロー・素材感による立体感
- **精密な余白（Spacing）**：情報を詰め込まず、視線が自然に動く空間
- **目的のある光（Light）**：グラデーション・グロー・ハイライトで焦点を作る
- **統制されたマテリアル（Material）**：ガラス・金属・石・布などの質感を一貫して使う

## レイヤリングルール

プレミアムページは必ず3〜4層で構成する：

```
Layer 4: テキスト・ラベル・数値（最前面）
Layer 3: カード・アイコン・図版（中前面）
Layer 2: グロー・シャドウ・アクセント光（中背面）
Layer 1: ベースグラデーション・テクスチャ（最背面）
```

各レイヤーに明確な役割を持たせる。全てを同じ深度に並べない。

## 余白・グリッドルール

- **安全マージン：** 上下左右8%（1080×1350の場合、約86px）
- **カード内パディング：** 最低24px
- **要素間隔：** 最低16px
- **テキスト行間：** ボディは1.6〜1.8、見出しは1.1〜1.3

---

## アイコン・図版ルール

- アイコンはファミリーを統一する（例：全ページでLine Awesome / Phosphor / Lucide）
- アイコンサイズは本文の2〜3倍を基準とし、強調要素には4〜5倍も可
- 矢印・番号・ラインは同じスタイルで統一する
- 図版（グラフ・フロー・表）はカード内に収め、境界線で区切る

---

## ページ番号の処理

全ページで統一した処理を行う。以下のいずれか：

- 右下にサークル＋番号（`● 01`）
- 左下にアンダーライン＋番号（`──01/08`）
- 上部にプログレスバー

---

## カバーページの必須要素

1. 強力なフック（見出し or 問い）
2. サブタイトル or 読者へのメッセージ
3. アカウント名・ハンドル（指定がある場合）
4. ビジュアルアンカー（人物・アイコン・図版のいずれか）

---

## 最終CTAページの必須要素

1. アクションの動詞（「保存」「フォロー」「DMを送る」「タップ」）
2. 理由・ベネフィット（なぜそのアクションを取るべきか）
3. アカウント名・ハンドル
4. 視線を誘導するビジュアル（矢印・下向き要素・強調色）
