# コンテンツアーキテクチャ参照ガイド

## 基本原則

コンテンツタイプに合わせてアーキテクチャを選ぶ。毎回同じテンプレートを使わない。
カバーで「なぜ読むべきか」を示し、各ページで「1つのアイデア」だけを伝え、CTAで「次の行動」を促す。

---

## コンテンツタイプ別アーキテクチャ

### 1. 教育・ハウツー（最も保存されやすい形式）

```
[カバー]    キャッチーな問い or 結論（「〜する3つの方法」）
[P2]        問題の共感（読者の現状を言語化）
[P3〜P(n-2)] 方法・ステップ・ポイント（1ページ1アイデア）
[P(n-1)]    よくある失敗・注意点（信頼感を高める）
[CTA]       次のアクション（フォロー・保存・リンク）
```

**ページ数の目安：** 6〜10枚
**強調点：** 各ページで必ず「使える知識」を1つ渡す

---

### 2. ストーリー・事例紹介（フォロワー獲得に強い）

```
[カバー]    変化の前後・ビフォーアフター
[P2]        Before（課題・状況の説明）
[P3〜P5]    プロセス（転換点・行動・発見）
[P6]        After（結果・変化）
[P7]        読者へのメッセージ（あなたも同じことができる）
[CTA]       フォロー・DM・問い合わせ
```

**ページ数の目安：** 7〜9枚
**強調点：** 感情の波を作る。P2で共感→P6で驚き→CTAで行動

---

### 3. リスト・まとめ（拡散・保存に強い）

```
[カバー]    「〜選」「〜リスト」「知らないと損な〜」
[P2]        リストの前提・背景（なぜこれが重要か）
[P3〜P(n-1)] 各アイテム（1ページ1項目）
[CTA]       保存・シェア・フォロー促進
```

**ページ数の目安：** 5〜8枚
**強調点：** 各アイテムにワンライナーの価値提案を添える

---

### 4. 比較・対比（フォロワーの意見を引き出す）

```
[カバー]    「AとBの違い」「〜vs〜」
[P2]        比較の文脈・前提
[P3〜P5]    各比較軸（1ページで1軸）
[P6]        判断基準・結論
[CTA]       「あなたはどっち？」コメント促進 or フォロー
```

**ページ数の目安：** 5〜7枚
**強調点：** 判断を押しつけず、読者が自分で選べる余地を残す

---

### 5. 商品・サービス紹介（問い合わせ・販売）

```
[カバー]    「こんな課題、ありませんか？」
[P2]        課題の深掘り（読者の痛みを言語化）
[P3]        解決策の提示（商品・サービスの概要）
[P4〜P5]   具体的な特徴・ベネフィット（1ページ1つ）
[P6]        社会的証明（実績・お客様の声・数字）
[CTA]       限定オファー or 問い合わせ導線
```

**ページ数の目安：** 6〜8枚
**強調点：** 特徴ではなくベネフィットで語る

---

## 骨格の構成要素（すべてのタイプ共通）

| 要素 | 説明 |
|------|------|
| コアクレーム | このカルーセルで伝えたい1つの主張 |
| 読者の課題 | 読者が抱えている問題・悩み |
| 約束するアウトカム | 読後に読者が得るもの |
| サポートするアイデア | 主張を支える3〜5つの論点 |
| 即時アクション | 読者が今すぐできること |
| 最終CTA | フォロー・保存・DM・URLクリックなど |

---

## ページ構成案の提示フォーマット

各ページを以下の形式で提示する：

```
【P〇】[ページの役割]
■ メイン見出し：「〜」
■ 本文コピー：
  〜（完全な文で記載）
■ 強調語：「〜」「〜」
■ ビジュアル方向性：[図版・アイコン・レイアウト指示]
■ 次ページへの橋渡し：「次は〜について」など
```

---

## 禁止事項

- 1ページに2つ以上のメッセージを詰め込まない
- 「まとめ」ページと「CTA」ページを混在させない
- ページ間に論理的なジャンプを作らない（読者が置き去りにならないよう順序立てる）
- 素材にない事実・数値・体験談を追加しない
