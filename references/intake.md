# インテーク参照ガイド

## 最小入力パス

カルーセルに必要な情報を最小の質問数で収集する。
**1ラウンドあたり最大3問**。ユーザーのメッセージから推測できる情報は聞かない。

---

## 必須フィールドと推測ルール

| フィールド | 推測できる場合 | 聞くべき場合 |
|-----------|--------------|------------|
| アカウント名 / ハンドル | プロフィール情報・過去のやりとりから | 一度も出てきていない |
| ターゲット読者 | 記事の内容・業種・トーンから判断可能 | 「誰に向けて」が不明 |
| ゴール（保存・フォロー・問い合わせ・販売） | CTAの有無・商品言及から推測可能 | 複数の可能性がある |
| ページ数 | 素材量から適切な枚数を判断可能（通常6〜10枚） | 明示的な制約がある |
| パレット / ブランドカラー | ブランドガイドライン・既存デザイン参照から | 指定なし・初回依頼 |
| 人物写真の使用 | 「顔写真なし」「自分の写真で」など言及があれば | 不明かつデフォルト外 |

---

## 高優先質問（最大3問から選択）

以下の中から、最も情報価値の高いものを選んで質問する：

1. **「このカルーセルの一番の目的は何ですか？**（保存してもらう／フォロワーを増やす／問い合わせを取る／商品を売る）」
2. **「読者はどんな人を想定していますか？**（職種・悩み・経験レベルなど）」
3. **「アカウント名（＠〜）を教えてください。**ページに入れます」
4. **「ブランドカラーや参考にしたいデザインはありますか？**なければTrust Premiumシステムで進めます」

---

## デフォルト設定（「プロの判断で進めて」と言われた場合）

| 項目 | デフォルト |
|------|----------|
| ページ数 | 8枚（カバー＋本文6枚＋CTA） |
| ビジュアルシステム | Trust Premium（ネイビー×ゴールド×ホワイト） |
| アカウント名 | ページフッターを空欄にして続行 |
| 人物写真 | 使用しない（指示があれば追加） |
| キャプション | 生成しない（リクエスト時のみ） |
| ファイル形式 | PNG、1080×1350 |

---

## インテーク省略のトリガー

以下の条件がすべて揃っている場合はインテークをスキップして構成案に進む：

- ターゲット読者が明確
- ゴールが明確（または素材から推測できる）
- コンテンツの素材が十分にある（記事・資料・箇条書きなど）

条件が揃っている場合は「〜という前提で進めます」と1文で明示してから次のステップへ。

---

## インテーク後の確認文（テンプレート）

```
以下の前提で進めます：
- 読者：[推測した読者像]
- ゴール：[保存 / フォロー / 問い合わせ / 販売]
- ページ数：[枚数]
- ビジュアル：[システム名 or カラー]
- アカウント：[@ハンドル or 空欄で続行]

問題なければ構成案を提示します。修正があればお知らせください。
```
