# 画像プロンプト参照ガイド

## プロンプト構造

各ページの画像プロンプトは以下の順序で記述する：

```
[キャンバス指定] → [デザインシステム] → [レイアウト] → [テキスト指示] → [図版・アイコン] → [禁止事項]
```

---

## 標準プロンプトテンプレート

```
縦型ソーシャルメディアカルーセルページ、1080x1350px、4:5アスペクト比。

【デザインシステム】
ベースカラー：[色] / アクセント：[色] / マテリアル：[素材感の説明]
レイヤー構造：背景グラデーション→グロー効果→カード→テキスト

【レイアウト】
[テキストと図版の配置を具体的に指示]
上下左右に8%（約86px）の安全マージンを確保。

【テキスト（完全引用・変更禁止）】
メイン見出し：「[承認済みの見出し全文]」
本文：「[承認済みの本文全文]」
強調：「[強調語]」を[アクセントカラー]でハイライト
ページ番号：「[番号]/[総ページ数]」を[配置位置]に

【図版・アイコン】
[具体的な図版・アイコンの説明、サイズ・配置・スタイルを指定]

【禁止事項】
余分なテキスト追加禁止、ロゴ・ウォーターマーク禁止、
多ページのコラージュ禁止、[人物がいない場合]人物禁止
```

---

## テキスト引用ルール

**最重要：承認済みコピーを完全引用する**

- 見出し・本文をプロンプト内に「」で囲んで全文記載する
- 生成中に省略・言い換え・短縮をしない
- 原文にない言葉を追加しない
- 改行位置の指示が必要な場合は `/` で区切りを示す

悪い例：「AIについての見出し」→ 良い例：「AIを使う人が年収を伸ばす3つの理由」

## ページタイプ別レイアウト指示

### カバーページ

```
上部1/3：アカウント名・タグライン（小さく）
中央1/3：メインキャッチコピー（最大フォントサイズ）
下部1/3：サブコピー＋ページ番号（01/[総数]）
中央に強調グロー、または大型アイコンを配置
```

### 情報ページ（箇条書き・ステップ）

```
上部：ページ見出し（全幅）
中央：情報カード（縦1列または2列グリッド）
下部：サマリー or 次ページ予告文（小さく）
右下：ページ番号
```

### 比較・対比ページ

```
中央に縦または横の分割線
左：A案（ラベル＋説明）
右：B案（ラベル＋説明）
分割線にアクセントカラーを使用
```

### CTAページ

```
中央上部：結論・約束文（大きく）
中央：アクション動詞（最大サイズ、アクセントカラー）
下部：アカウント名＋ハンドル
矢印または下向き要素で視線を誘導
```

## 人物写真を含む場合の追加指示

```
【人物処理】
元の顔・体型・肌トーン・髪・表情・服装を完全保持。
背景を除去してデザイン背景に配置。
テキストと人物が重ならない配置を維持。
美肌加工・骨格変更・イラスト化禁止。
```

---

## 品質を下げる表現（プロンプトで避けること）

- 「シンプルに」→ ビジュアル的な貧困を招く
- 「テキストを入れて」だけ → 配置・サイズ・色を具体的に指定する
- 「おしゃれに」「かっこよく」→ 具体的なシステム名・色・素材感で指定する
- 短い見出しのみ → 本文コピーも完全に記載する

---

## 生成後の確認チェックリスト

- [ ] テキストが承認済みコピーと一致している
- [ ] 見出しの文字が読める（グラデーション・背景と十分なコントラスト）
- [ ] ページ番号が正しい
- [ ] 余分なテキスト・ロゴが入っていない
- [ ] 安全マージン内にすべての要素が収まっている
- [ ] 人物がいる場合、テキストと重なっていない
