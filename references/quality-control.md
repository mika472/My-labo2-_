# 品質管理（QA）参照ガイド

## QAの基本原則

- **サムネイルのみで承認しない。** 各ページを100%表示で確認する
- **ZIPを有効と宣言するのは、すべての画像がデコードされアーカイブテストが成功した後のみ**
- **数値の修正は数字だけでなく、ラベル・単位・比較条件・関連するビジュアル要素もすべて確認する**

---

## ページレベルQAチェックリスト

各ページ生成後に以下を確認する：

### テキスト精度
- [ ] メイン見出しが承認済みコピーと完全一致している
- [ ] 本文コピーが承認済みテキストと完全一致している（省略・言い換えなし）
- [ ] 強調語が指定どおりにハイライトされている
- [ ] ページ番号が正しい（例：03/08）
- [ ] アカウント名・ハンドルが正確に表示されている（指定がある場合）

### 視認性
- [ ] 見出しのコントラスト比が背景に対して十分（目安：4.5:1以上）
- [ ] 本文テキストがスマートフォンサイズで読める
- [ ] テキストと画像・図版が重なっていない
- [ ] 人物がいる場合、テキストにかかっていない

### デザインの一貫性
- [ ] 前のページと同じパレット・アクセントカラーを使用している
- [ ] アイコンファミリーが統一されている
- [ ] 余白・カードのサイズ感が統一されている
- [ ] ページ番号の処理スタイルが統一されている

### 安全マージン
- [ ] すべての要素が上下左右8%（約86px）のマージン内に収まっている
- [ ] テキストが端で切れていない

### 禁止事項チェック
- [ ] 余分なテキスト（プロンプトにない文字）が入っていない
- [ ] ウォーターマーク・ロゴが入っていない
- [ ] 依頼されていない人物が入っていない
- [ ] 複数ページのコラージュになっていない

---

## 納品物QAチェックリスト

### ファイルの確認
- [ ] ファイル名がゼロパディングされている（例：carousel_01.png）
- [ ] 数値順に並んでいる
- [ ] すべてのページが揃っている（欠番なし）
- [ ] 各ファイルが完全にデコードできる（破損なし）

### 解像度・サイズ
- [ ] 各画像が1080×1350px（または適切な1:1.25比率）
- [ ] 安全でないクロッピングが発生していない
- [ ] ファイルサイズが適切（1枚あたり1〜5MB程度）

### ZIPアーカイブ
- [ ] ZIPが正常に開ける
- [ ] 含まれているページ数が期待値と一致する
- [ ] アーカイブテストコマンドが成功する

```bash
python3 -c "import zipfile; z=zipfile.ZipFile('output.zip'); z.testzip(); print('OK')"
```

## 修正リクエストへの対応プロセス

### 1. ターゲットの特定
```
修正対象：P[番号]の[具体的な要素]
変更前：「[現在の内容]」
変更後：「[正しい内容]」
変更しない要素：[リスト]
```

### 2. 単一変更の原則
- 1リクエスト = 1変更
- 複数の修正は個別に処理する
- 関係のない要素を再レンダリングしない

### 3. 数値修正の追加確認
数値を変更する際は以下もあわせて確認：
- ラベル（単位・条件文）は正しいか
- グラフ・矢印・カードとの関連付けは正しいか
- 比較対象の数値との整合性は取れているか

### 4. 修正後の報告
```
【修正完了報告】
修正したもの：P[番号]の[要素] → 「[変更後]」
変更しなかったもの：[リスト]
```

## よくある品質問題と対処法

| 問題 | 原因 | 対処 |
|------|------|------|
| テキストが途中で切れる | 安全マージン不足 | 左右マージンを増やしてリジェネレート |
| 見出しが読めない | 背景とのコントラスト不足 | テキストに影・アウトライン追加を指示 |
| 承認済みと異なるコピー | プロンプトへの引用漏れ | 完全引用を含むプロンプトで再生成 |
| デザインが前ページと異なる | パレット指定の漏れ | ビジュアルシステムの定型文を再追加 |
| 余分なテキストが入る | 禁止事項の記載漏れ | 「追加テキスト禁止」をプロンプト末尾に追加 |
| 人物の顔が変わる | 同一性保持指示の漏れ | 元の特徴を具体的に列挙して指示 |

## コンタクトシートの活用

コンタクトシートは**全ページの概観確認のみ**に使う。

- デザインの統一感を確認する
- ページ順が正しいか確認する
- 明らかな欠落を検出する

コンタクトシートで見えないもの（テキストの正確性・コントラスト比・文字の読みやすさ）は、個別ページを拡大して確認する。
