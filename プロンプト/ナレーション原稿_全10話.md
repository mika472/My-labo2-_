## 確定した生成方式（実測にもとづく・v2）

エンジン：text2speech_v2 / variant: elevenlabs / voice: Hana（preset, c25f78a0-714e-42af-8da3-a399cef94968）
このエンジンは読み上げテキストしか受け取らない（speed も style も渡せない）。
したがって演出はすべてテキスト側で実装し、1.3倍は編集アプリでかける（ピッチ補正あり）。

### 生成単位：1話まるごと1本

ショット単位で切って生成すると「間」が音声に含まれず、編集で無音を挟む手間が出るうえ、
文の流れが切れてイントネーションが不自然になる。1話を1本の通しで生成すること。
空行が0.4〜0.7秒の間になるので、間の設計はテキストの改行で行う。

実測（第1話）：テキスト設計後の生成尺 39.68秒 → 1.3倍で 30.5秒（枠30秒）。

### テキスト側で演出する（渡されたナレーション指示の実装）

| 指示 | テキストでの実装 |
|---|---|
| 発音補助 | 誤読リスクのある語だけひらがなに開く（ひとむね／ななつ／ごじゅうにさい） |
| 数字の読み | 誤読リスクのあるものだけ開く。年号など明確なものは漢数字のまま |
| 句読点の間の使い分け | 軽い区切り=読点、通常=句点、意味の切り替わり=空行 |
| 単語ごとに切らない | 不要な読点を削り、意味のまとまりで一息にする |
| 一定速度で読まない | 導入は読点を足してゆっくり、展開部は読点を減らす |
| 強調は間で作る | 最重要の一文の前後を空行で挟む（例：「自分で書いた、遺書だった。」） |
| 原稿を変えない | 変更してよいのは句読点・改行・読み仮名・間のみ。意味と事実は不変 |

## ナレーション仕様（全10話の標準）

| 項目 | 設定 |
|---|---|
| 性別 | 女性 |
| 年齢感 | 30代後半〜40代 |
| トーン | 落ち着いた低め。ドキュメンタリーの語り。感情を張らない。ポエム調・広告調にしない |
| 速度 | 通常の1.3倍 |
| モデル | seed_audio |
| パラメータ | voice_type: preset / speech_rate: 1.3 |

速度の注意：speech_rate を直接1.3にするのが最短だが、日本語は子音が潰れやすい。
1.2で生成して残りを編集で詰めるほうが自然になる場合がある。最初に1.2と1.3を聴き比べること。

台本の秒数はすでに1.3倍を前提に計算している（約10文字／秒）。
通常速度で生成した音声が各ショットより1.3倍長くなるのは正常。
