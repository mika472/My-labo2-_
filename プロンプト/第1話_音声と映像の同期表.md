# 第1話「机の中の遺書」音声と映像の同期表

エンジン：text2speech_v2 / variant: elevenlabs / voice: Hana（preset, c25f78a0-714e-42af-8da3-a399cef94968）
ElevenLabsは生成時に速度も感情も指定できない（voice_id のみ）。
したがって感情は句読点・改行・呼吸位置で作り、速度はショットごとに編集で変える。

## 制作順序（重要）

映像を先に作らない。次の順で進める。

1. ショット単位でナレーションを生成する
2. 生尺を実測する
3. 一文ごとの感情設計から再生速度を決める
4. 「生尺 ÷ 速度」でそのショットの映像秒数を確定する
5. その秒数で image-to-video を生成する

実際の映像がこの秒数からズレた場合は、
再生速度 = 音声の生尺 ÷ 映像ショットの実尺
で計算し直す。

## 一文ごとの速度設計の原則（第2話以降にも適用）

| 内容 | 速度 |
|---|---|
| 話の導入 | 1.10〜1.20倍 |
| 事実・数字の提示 | 1.30〜1.40倍 |
| 反転・引きの直前 | 1.10〜1.20倍 |
| 説明・経過 | 1.35〜1.45倍 |
| 感情の頂点（開示・喪失・決断） | 0.95〜1.10倍 |
| 視聴者への語りかけ・CTA | 1.05〜1.15倍 |

平均は1.15〜1.25倍に収まる。渡されたナレーション仕様書の第10条「感情的なドラマは0.95〜1.15倍」と、
SNSショート動画の1.15〜1.3倍の中間を取った設計。
一定速度で読ませないこと（同第11条）が、エモーショナルに聞こえるかどうかを決める。
