# 00｜BGM設計・全10話

## シリーズを貫く5つの原則

1. 主題モチーフはピアノ3音。第1話の引き出しで提示し、第9話で再提示し、第10話で完奏する。それ以外の場所では鳴らさない
2. 感情の頂点では音を止める。盛り上げない。第1話の遺書、第6話の赤色灯、第8話のコロナ、第9話の一言。すべて無音か環境音だけ
3. 楽器はシリーズの進行と一緒に増える。ピアノ1台から始まり、第7話でようやく弦が開く。増えた音は第8話で一度全部消える
4. 赤色灯には音を当てない。第2話と第6話、二度とも環境音だけで見せる
5. 調は第7話で初めて長調へ転じる。「初めて人に助けられた」の瞬間。それまで一度も明るくしない

## 各話の詳細

### 第1話 机の中の遺書
- 0:00〜0:05 音楽なし。街の環境音だけ
- 0:05 ピアノを1音ずつ、ごく静かに
- 0:08「けれど彼女は」で低い持続音を薄く。空気が変わったと分からせる
- 0:12 マッチカットでピアノを一度止める。部屋の静けさだけ
- 0:18 引き出しの音、紙を開く音、鉛筆の音。これがこの話のBGM
- 0:20「遺書だった。」の直後、0.5秒の完全な無音
- 0:21 ピアノが1音だけ戻る（主題モチーフの提示）
- 0:24 ストリングスを最小音量で
- 0:28 赤い光が障子を横切るところで低いパーカッションを1発
- END CARD へ余韻だけ

### 第2話 警察が来る家
- 冒頭は第1話の残響から継ぐ
- 0:03〜0:10 音楽を完全に抜く。ガラスの割れる音、遠い赤色灯の回転音だけ
- 0:10 母の台詞からチェロのロングトーンを1本
- 0:16 母の靴がない玄関でピアノが戻る。ただし単音のみ
- 0:21 13歳の場面で音を減らす
- 0:26「お前がいない方が楽」で完全無音
- 0:28 ドアが開く音。外の光でピアノ1音。それを長く伸ばして次話へ

### 第3話 1000万の借用書
- 0:03 同棲の場面で、シリーズで唯一の長調のニュアンスを一瞬だけ
- 0:08 出産で温かさを保つ
- 0:12 借用書を広げた瞬間、長調が消える。低弦が入る
- 0:18 父の場面はピアノを止め、パチンコ台の音だけ
- 0:24 123万円のくだりで音が少しだけ軽くなる。人間味。すぐ戻す
- 終わりは低弦だけ残す

### 第4話 生後2ヶ月で、店に立つ
- 物語が動き出す話。刻みの弱いパーカッションが初登場する
- 0:03 託児所の場面はまだピアノのみ
- 0:08 六本木でパーカッションが入る。テンポ76
- 0:14 借用書に線が引かれるたび、パーカッションが1つずつ減る（借金が減る音の見立て）
- 0:20 病室で全部抜く。点滴の音だけ
- 0:25 通話履歴でパーカッションを止め、ピアノ1音で切る
- 無音で次話へ

### 第5話 スーツと、靴だけ
- 第4話の無音を引き継ぐ。0:03まで音を入れない
- パーカッションは一切使わない。彼女が動いていない話だから
- 0:03 車内でピアノが単音で戻る
- 0:09 浮気相手の家の玄関で無音。インターホンの音だけ
- 0:15 スパでピアノが戻る
- 0:25 連れ去りで音を消す。足音と車の音だけ
- 完全な無音で次話へ

### 第6話 腫れた顔で、笑った（最重要）
- 0:00〜0:10 音楽を入れない。足音、鞄が落ちる音、赤色灯の回転音だけ
- 0:10 鏡の前でピアノが1音ずつ戻る。テンポ56。シリーズで最も遅い
- 0:16 No.1のボードでも音を足さない。ここで盛り上げると作品が壊れる
- 0:20 給与明細と封筒の場面から低弦が加わる
- 0:25 化粧を落とす場面で低弦だけ残す
- 0:27 名刺が差し出されるところで、初めて高音のピアノが1音鳴る。次の街の予感
- その高音を残して次話へ

### 第7話 花を贈り合う街
- シリーズで初めて音が開く話
- 0:03 前話の高音から始まる
- 0:08 転落の区間は音を抜く。空いた席の静けさ
- 0:14「初めて人に助けられた」でニ長調へ転調する。シリーズ唯一の転調点
- 0:21 花が並ぶ路地で弦と高音が開く。ここがシリーズ初の開放
- 0:26「人のために生きることを覚えた」で最も温かい和音
- 温かいまま次話へ

### 第8話 銀座に、一棟
- 0:03 40歳の場面は弦を薄く
- 0:13 決断でテンポが80へ上がる
- 0:17 看板に灯りがつく瞬間、シリーズ最大の高揚。ただし音量は控えめに保つ
- 0:24 コロナで全楽器を一瞬で切る。フェードではなくカット
- 0:24〜0:30 シャッターの音と振込のクリック音だけ
- 無音で次話へ

### 第9話 2億
- ピアノのみに戻る。第1話とまったく同じ音色を使う
- 0:03 株の話でピアノが単音
- 0:09〜0:16「あなただけ買わないんだね」の全区間を完全な無音に。グラスの音だけ
- 0:16 振込の場面でもピアノは戻さない。打鍵音だけ
- 0:21 通じない電話のアナウンス。無音のまま
- 0:26「人を見る目だった」で主題モチーフの3音を再提示する。ここが回収点
- その3音を残して次話へ

### 第10話 最後の夢
- 第9話の3音から始まる
- 0:03 現在の場面で弦が加わる。ただし音量を上げない
- 0:13 寺の縁側で、初めて朝の環境音を入れる。鳥、風、箒の音
- 0:19 墓の場面は音を減らす
- 0:24 ドアを開ける直前に0.5秒の無音
- 0:25 ドアを開けてスタッフを迎え入れる。ここで最大にしない。ピアノ1音と弦の余韻だけ
- 第1話の3音がここで完奏する
- QR画面まで余韻を伸ばし、自然に消す

| 場面 | 使う音 |
|---|---|
| 1話 引き出し | 引き出しが開く音、紙を開く音、鉛筆の音 |
| 2話 両親の争い | ガラスの割れる音、遠い赤色灯の回転音 |
| 4話 病室 | 点滴の音 |
| 5話 浮気相手の家 | インターホンの音 |
| 6話 暴力〜救急車 | 足音、鞄が落ちる音、赤色灯の回転音 |
| 8話 コロナ | シャッターを下ろす音、振込のクリック音 |
| 9話 詐欺 | グラスを置く音、通じない電話のアナウンス |
| 10話 寺 | 鳥、風、箒で掃く音 |
