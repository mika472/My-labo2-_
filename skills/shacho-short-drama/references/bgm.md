# BGM設計リファレンス

短尺ドラマのBGMは、盛り上げる道具ではなく**どこで音を止めるか**を決める設計。
感動的な場面で音を足すと安っぽくなり、企業PRに見える。

---

## シリーズを貫く5つの原則

1. **主題モチーフを1つだけ作る。**ピアノ3音程度の短いもの。第1話で提示し、
   終盤で再提示し、最終話で完奏する。それ以外の場所では鳴らさない
2. **感情の頂点では音を止める。**最大の開示、暴力、喪失、裏切り。すべて無音か環境音だけ
3. **楽器はシリーズの進行と一緒に増やす。**ピアノ1台から始め、転機の話でようやく弦が開く。
   増えた音は挫折の話で一度全部消す
4. **繰り返す映像モチーフには音を当てない。**赤色灯なら、二度とも環境音だけで見せる
5. **調は物語の転機で一度だけ転じる。**それまで一度も明るくしない

---

## 各話に決めること

| 項目 | 内容 |
|---|---|
| 編成 | どの楽器を使うか。前話から増えたか減ったか |
| テンポ／調 | BPMと調性 |
| 入り | 何秒から、どの楽器で |
| 無音にする場所 | 秒単位で指定。ここが設計の本体 |
| 頂点 | 作るか作らないか。作らない話のほうが多い |
| 終わり方 | 最後の音 |
| 次話への渡し | 余韻を残すか、無音で渡すか |

無音で次話に渡すと、次話の冒頭が刺さる。挫折の話の後には有効。

---

## 効果音を優先する場面を明示する

BGMより効果音が主役になる場面は、発注時に別立てにしないと落ちる。
一覧を作って渡す。

例：
- 引き出しを開ける音、紙を開く音、鉛筆の音
- ガラスの割れる音、遠い赤色灯の回転音
- 点滴の音
- シャッターを下ろす音、振込のクリック音
- 通じない電話のアナウンス
- 鳥、風、箒で掃く音

こうした音が主役の場面では、**環境音そのものがBGM**になる。
「ここは音楽なし、環境音のみ」と台本に書く。

---

## 最終話の締め方

CTA直前は、シリーズの結論にあたる。ここで音を最大にすると企業PRになる。

推奨：直前に0.5秒止める → ピアノ1音と弦の余韻だけ → 主題モチーフを完奏 →
QR画面まで伸ばして自然に消す。

盛り上げないことが、結果として一番効く。
